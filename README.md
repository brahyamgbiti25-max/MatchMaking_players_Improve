🎮 MatchMaking Backend ServiceA robust, secure Spring Boot backend application designed to handle player registration, email account verification, password resets, and an automated skill-based matchmaking queue system using robust database relations and concurrency handling.🏗️ Architecture & Core FeaturesJWT-Based Stateless Security: Custom security filter chain using OncePerRequestFilter to secure endpoints, extract roles, and validate tokens without keeping server-side sessions.Skill-Based Matchmaking Queue: Dynamically pairs users based on a skill rating window (+/- 150 points) and queue timing order.Concurrency Control: Utilizes Pessimistic Locking (@Lock(LockModeType.PESSIMISTIC_WRITE)) at the database level to prevent race conditions when multiple players search for a match simultaneously.Email Verification & Account Management: Integrated JavaMailSender to dispatch secure token-based verification links for signup confirmation and password recovery.Database Management: Uses Hibernate ORM with auto schema updates and connection pooling for MySQL.📋 PrerequisitesBefore running this project, ensure you have the following installed on your local machine:Git: To clone the repository.Docker Desktop: To containerize and run the application and database stacks seamlessly.(Note: You do NOT need to install Java or MySQL natively if running through Docker).⚙️ Environment ConfigurationCreate a .env file in your root project directory to securely pass your credentials without exposing them in your codebase:SPRING_DATASOURCE_USERNAME=root
SPRING_DATASOURCE_PASSWORD=your_db_password
JWT_SECRET=YourSuperSecretJwtKeyHere
SPRING_MAIL_USERNAME=your-email@gmail.com
SPRING_MAIL_PASSWORD=your-gmail-app-password
APP_FRONTEND_URL=http://localhost:4200
